Local agent (host-bound desktop tools — ADR-0009)
  Desktop UIA cannot run in a pod. On the user machine:

    export VYOMEL_API_BASE=http://<api-host>:{{ .Values.api.service.port }}
    export VYOMEL_LOCAL_AGENT_TOKEN=<from secret local-agent-token>
    vyomel agent

Failover notes
  - API pods are interchangeable; sessions for local agents are sticky per API replica
    (reconnect if the API pod restarts).
  - Scheduler: run ≥2 replicas; only the Redis lock holder ticks. Lock TTL={{ .Values.scheduler.leader.ttlSeconds }}s.
  - Workers: crash → lease reaper reclaim; HPA scales on queue depth when metrics adapter is present.
  - Postgres/Redis: single-replica StatefulSets with PVCs; restore from volume snapshot for DR.
